# Семейная медкарта (демо-прототип)

Анализы и замеры всей семьи в одном месте: фото или PDF бланка → таблица показателей → динамика → сводка для врача на одну страницу A4.

**Демо-версия. Не загружайте реальные медицинские документы.** Данные хранятся только в `localStorage` браузера.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173/. Кнопка «Заполнить демо-данными» создаёт семью из трёх человек. Ссылка `/?demo=1` делает то же при загрузке.

## Консьерж-слой

- **Помощник** — поручения («запросить документы», «подготовить к визиту») со статусами и переписка. В демо ответы имитируются.
- **Досье** — все документы профиля: анализы, выписки, снимки, рецепты, прививки, полисы; паспорт здоровья на двух языках.
- **Круг заботы** — кто из близких, сиделок и врачей видит данные, сроки доступа, временная ссылка для врача и журнал просмотров. В демо приглашения и ссылки не работают.

## Устройство

- `src/lib/recognize.js` — единственная точка распознавания бланка. Сейчас заглушка с примером общего и биохимического анализа крови; чтобы подключить ИИ, добавьте провайдер в `PROVIDERS` и укажите его в `ACTIVE_PROVIDER`.
- `src/lib/indicators.js` — справочник из 21 показателя: единицы, пересчёт, нейтральные пояснения.
- `src/lib/store.js` — модель данных (Profile, LabResult, Measurement, VitalSign) и хранение в браузере.
- Отклонения подсвечиваются только относительно референса лаборатории; диагнозов, прогнозов и советов нет.
- «Скачать PDF» открывает печать браузера — выберите «Сохранить как PDF».
